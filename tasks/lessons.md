# Lessons

- **Replicating a workbook with an optimizer -> freeze its sampled objective and length convention before improving numerics -> check shared numeric references and report analytic length separately.** A better length constraint can silently change an unconstrained formfit.
- **Shipping CAD sources from a machine without the CAD host -> supply native designer control IDs and creation steps, keep binaries absent -> track compiler, UI import, licensing and reopen tests as unverified even when pure numerics pass.**
- **Packaging sensitive-source work -> inspect staged blob bytes and pack an explicit file list -> exercise disguised containers, symlinks, a clean working copy over an unsafe index, and post-manifest tampering.** File extensions and .gitignore alone are insufficient.

- **Matching source archive hashes across Windows and Unix -> normalize checkout line endings and ZIP creator system as well as entry order/time/mode -> compare CI hashes and test platform-default metadata variation.**
