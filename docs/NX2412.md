# Run the wrinkle calculator in NX 2412

## What you need

Use **`ready-to-run/NX_WrinkleCalculator.py`** on a Windows workstation with NX 2412 and permission to play Python journals. The standalone file includes the calculation core, the Windows input dialog, and the illustrated report. NX's Python interpreter needs the standard `ctypes` module and its `_ctypes` extension. Check their availability in your installation. For a designer-built interface, see the [optional Block Styler guide](NX2412-BlockStyler-optional.md).

Windows CI exercises the actual dialog outside NX. The journal startup, bundled Python compatibility, dialog focus and modality, licensing, and installation still need verification in NX 2412. Ask your workstation administrator about journal permissions and any applicable licensing.

## 1. Download the journal

1. Open the public [repository on main](https://github.com/TimKleindick/cad-embossing-wrinkle-calculator/tree/main) and choose **Code > Download ZIP**.
2. Save the ZIP locally, for example under `C:\CAD-Test\Wrinkle`. In Windows Explorer, right-click it and select **Extract All**. Open **`ready-to-run`** in the extracted folder.
3. Locate **`NX_WrinkleCalculator.py`**. If necessary, enable **View > Show > File name extensions** in Explorer and check that the file ends in `.py`.
4. Alternatively, open the [journal on GitHub](https://github.com/TimKleindick/cad-embossing-wrinkle-calculator/blob/main/ready-to-run/NX_WrinkleCalculator.py) and select **Download raw file**. The source starts with `# GENERATED`. For a repeatable workstation test, record the Git commit you downloaded.

A source preview ZIP built with the repository's packaging tool also contains the startup file under `ready-to-run`. Keep the original workbook outside the repository and test evidence.

## 2. Run the journal

1. Start NX 2412. If your configuration only enables **Journal > Play** with a part open, use a blank test part. Values in the calculator are always in millimeters.
2. Find **Journal Play** in the command finder or use **Tools/Developer > Journal > Play** if visible in your role.
3. Select **Python source files (*.py)** or all supported journal files in the file chooser. Open **`NX_WrinkleCalculator.py`** from the extracted folder.
4. If your NX role requires a journal language setting, check **File > Preferences > User Interface > Tools > Journal > Journal Language > Python**, then play the journal again. The exact options may vary by role and installation.
5. The Windows dialog presents **Undeformed wall length l1 [mm]**, **Deformed wall length l2 (neutral fibre) [mm]**, an optional **Wall thickness [mm]**, **Calculate**, **Close**, and a text results field. Play the file through NX to test its integration with your workstation.

## 3. Check the illustrated results

1. Enter `l1 = 40` and `l2 = 30` in mm. The calculator uses `l1` as the target length along the cosine and `l2` as the horizontal span between the endpoints of the deformed neutral-fibre profile. Select **Estimate strain from wall thickness**, enter `2`, and choose **Calculate**. Use a decimal point or comma, with no grouping separators, units, or exponents.
2. The Windows default browser opens **Wrinkle geometry**, the same offline English report as CATIA. The sketch labels the three circular arcs with their common radius. Values are displayed to two decimal places. The journal retains text results in its dialog if the report fails to open. The HTML file is in the Windows temporary directory.
3. Open **More information** to see the length and shape comparison. The first row shows the entered `l1`. The relative length deviation still compares the fitted polyline with `l1`.

| Quantity | Report value |
|---|---:|
| Undeformed wall length l1 | 40.00 mm |
| Deformed wall length l2 (neutral fibre) | 30.00 mm |
| Circular arc radius R | 5.03 mm |
| Fitted profile height h | 12.23 mm |
| Flank angle φ | 49.84° |
| Analytical length of the fitted profile | 40.17 mm |
| Fitted polyline length deviation from l1 | +0.43% |
| RMS and maximum sampled vertical shape deviations | 0.10 / 0.18 mm |
| Cosine curvature at the crest | 3.71 mm / 26.93% |

4. In **Cosine bending estimate**, check the minimum cosine radius and estimated outer-fibre bending strain. The text results show the same estimate. The radius is not the fitted circular-arc radius. The simplified bending estimate does not predict cracks or assign a fracture risk band.
5. Turn the wall thickness option off and calculate again. The cosine radius remains visible; strain is not calculated.
6. Try `30 / 30`. The flat profile has no finite cosine radius. When thickness is supplied, the cosine strain estimate is zero. At `80 / 60` with thickness `4`, absolute lengths double and angles, relative errors and strain stay the same.
7. Try `29 / 30` and then text in a length field. The text results should be replaced by an error. Supported lengths are 0.001 to 1,000,000 mm with `l2 <= l1 <= 2*l2`. Optional wall thickness ranges from 0 to 1,000,000 mm.
8. Copy the text results with **Ctrl+C** or use the report for the test record. Check that **Close**, **Esc**, and the title-bar close button return control to NX.

## 4. Troubleshoot the workstation

| Observation | Check |
|---|---|
| Journal file does not appear | Check the extracted folder, the `*.py` file filter, and the file extension. |
| Syntax error at the beginning of the file | Download the raw file again and ensure its first line starts with `# GENERATED`. |
| Missing `_ctypes` or `ctypes` | Record the NX build and error and check the supported NX Python installation with IT. The optional Block Styler path has separate setup requirements. |
| WinError or dialog never opens | Record the complete error, Windows and NX builds, Python version, architecture, and journal command. Integration with this host remains unverified. |
| NX seems blocked | Look for the modal dialog in the taskbar or use **Alt+Tab**. Check that closing it returns focus to NX. |
| The text results appear but the report does not | Check the Windows default application for HTML and whether NX can write to the temporary directory and open that application. |
| Input is rejected or results differ | Verify the input format, mm units, length range, thickness option and downloaded version. See the [calculation method](MATHEMATICS.md). |

Record the source commit, NX and Windows builds, bundled Python version, inputs, results, browser launch, and close/reopen behavior. Verify that the journal leaves the part geometry and document state unchanged.
